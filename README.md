# ForbiddenScan
Консольное приложение .NET 8. Запуск из корня репозитория:
```powershell
dotnet run --project src -c Release -- self-test
dotnet run --project src -c Release -- scan --algorithm aho
dotnet run --project src -c Release -- benchmark --iterations 5
dotnet run --project src -c Release -- report --run-dir reports/КАТАЛОГ
```
Дополнительные параметры: --input DIR, --run-dir DIR. Алгоритмы: naive, hash, aho.
Входные файлы находятся в InputTerr. Каждый непустой блок нумеруется с 1 в своем файле; строки из пробелов считаются разделителями. Последний блок обрабатывается без завершающего разделителя. UTF-8, BOM поддерживается.

Поиск полного названия после ToUpperInvariant. Пустые названия исключаются, дубликаты удаляются, края названий обрезаются. Внутренние пробелы и пунктуация сохраняются. По обеим сторонам совпадения не должно быть буквы, цифры или подчеркивания. Кавычки и дефисы являются разделителями. Частичные названия, опечатки и синонимы не учитываются. После первого совпадения проверка блока завершается. В matches.log записываются все исходные участники, включая повторы.

naive: последовательный поиск каждой подстроки и проверка границ.
hash: HashSet всех слов из списка отбрасывает строки без общих слов, затем выполняется naive. Названия без слов проверяются отдельно.
aho: бор с суффиксными ссылками, поиск всех шаблонов за проход, проверка границ найденных кандидатов.

Все документы обрабатываются последовательно; в памяти находится текущий блок, структуры шаблонов и идентификаторы найденных блоков. Benchmark выполняет один прогрев каждого алгоритма, затем повторные проходы с циклической сменой порядка. Сравниваются точные последовательности идентификаторов блоков и их общее количество. Время включает чтение, разбор, нормализацию и поиск, но не запись журналов. Кеш файлов прогрет. Подготовка каждого алгоритма измеряется один раз отдельно (может включать JIT); общая загрузка списка также отдельно. Полные блоки записываются отдельным проходом после измерений. Для scan запись блоков тоже вынесена в отдельный проход.

reports/<дата_время>: run.log, matches.log; benchmark дополнительно сохраняет results.json и report.html. HTML можно пересоздать без измерений. Сведения о среде берутся из сохраненных результатов. В терминале только сводка. Требуется SDK .NET 8; BAT и внешние пакеты не используются.
